# OilStudio — photo to oil painting

A Flask application that turns photographs into oil paintings. Every stroke
is generated by a painting engine rather than by an image filter: the photo
is simplified into colour masses, a structure tensor decides which way the
brush runs, and the picture is built coarse-to-fine, one bristled stroke at
a time. The accumulated paint height is then lit as an impasto relief.

## Desktop app (Windows and macOS)

OilStudio also runs as a normal desktop program in its own window, with no
browser or terminal needed.

**Try it from source:**

```bash
pip install -r requirements.txt
python desktop.py
```

**Build the app to share:**

| | Command | Result |
|---|---|---|
| Windows | double-click `build\build_windows.bat` | `dist\OilStudio\OilStudio.exe` + `dist\OilStudio-windows.zip` (send the zip: the .exe alone will not run) |
| macOS | `bash build/build_mac.sh` | `dist/OilStudio.app` + `dist/OilStudio-mac.zip` (send the zip) |

Build the Windows version on Windows and the Mac version on a Mac. Add
`build/icon.ico` (Windows) or `build/icon.icns` (Mac) for an app icon
before building. Both need Python 3.10+ (on a Mac use python.org or Homebrew
Python, not Apple's 3.9). Windows builds into `.build-venv`, the Mac into
`.build-venv-mac`, so the same folder can be copied between the two.
The Mac app is built for the chip of the Mac that builds it (Apple Silicon
or Intel). Packs whose `pack.json` points to a folder outside the pack
(like the `canvas-oil-painting` example) are not put into the app, because
that path only exists on the build machine.

How the packaged app behaves:
* It starts a private server on a random local port that only this
  computer can reach, and shows it in a native window: WebView2 on Windows
  (built into Windows 10/11), WebKit on macOS.
* Action packs live in **Documents/OilStudio Actions**; the 📂
  button in the Actions panel opens that folder. Presets and temporary
  files go to `%APPDATA%\OilStudio` (Windows) or
  `~/Library/Application Support/OilStudio` (Mac).
* The Mac app is not signed. The first time, open it once, then click
  **Open Anyway** in System Settings → Privacy & Security. If macOS
  says the app is damaged, run `xattr -cr /Applications/OilStudio.app`.
* Closing the window quits the app.

## Protected builds for clients (no readable code)

Send clients a **protected** build - never this project folder, which is
the full source code:

| | Command (on your own computer) | Send to the client |
|---|---|---|
| Windows | double-click `build\build_windows_protected.bat` | `dist-protected\OilStudio-windows.zip` |
| macOS | double-click `Build OilStudio Protected (Mac).command` | `dist-protected/OilStudio-mac.zip` |

`build/protect.py` makes a copy of the project and, on that copy:
compiles every Python module (server, painting engine, planner, action
player) to machine code with Cython and deletes the source; minifies the
JavaScript and CSS (with Node.js installed the JavaScript names are
scrambled as well); packs the templates, scripts and styles, compressed,
inside the compiled program; then starts the result and checks it works
before PyInstaller turns it into the app. The client installs nothing:
Python and every library are inside the app.

The build needs a C compiler on the build machine: the free *Build Tools
for Visual Studio* (C++) on Windows - the script installs it with winget
if it is missing - or the *Xcode Command Line Tools* on a Mac. Node.js
(nodejs.org) is optional and gives stronger JavaScript protection.

What it protects, honestly: Python code becomes machine code - reading it
needs a reverse engineer. The JavaScript runs in the window, so it can
never be fully hidden; minified and scrambled it is very hard to follow.
Action packs (`ps_actions`) and sample photos are data and stay
as files. Your own project is not changed: keep developing as usual and
rebuild for each release.

## Running it in the browser

```bash
pip install -r requirements.txt
python app.py            # http://localhost:5000
```

Set `OILSTUDIO_SECRET` in production so sessions survive a restart:

```bash
OILSTUDIO_SECRET="a-long-random-string" PORT=8080 python app.py
```

For a real deployment put it behind a WSGI server:

```bash
pip install gunicorn
OILSTUDIO_SECRET=... gunicorn -w 1 --threads 8 -t 300 -b 0.0.0.0:8080 app:app
```

Use **one worker with threads**: a session's image lives in that worker's
memory. To run several workers, move the session store to Redis or to disk.

## The default settings

Opening the app already gives the "painted photograph" look — faithful
colour, confident directional strokes, broad sweeps in the open background
and fine work on faces and detail. These defaults were tuned by running
real photograph/painting pairs through the engine and comparing the two:

| | | | |
|---|---|---|---|
| Simplicity | 3 | Stroke Thickness | 12 |
| Direction | 15 | Max Stroke Length | 22 |
| Wide Background Strokes | 9 | Min Stroke Length | 35 |
| Expression | 20 | Hair Thickness | 32 |
| Filling | 94 | Brush Density | 52 |
| Relief | 30 | Intensity | 70 |
| Lightening | 2 | | |

Decoration is off by default, because a photograph that is already lit and
graded does not need a canvas weave or a vignette on top. Turn on **Light**
when you want the dark, glowing old-master treatment.

## Painting parameters

**Image** — *Simplicity* (1–15) how far the photo is abstracted into flat
colour masses · *Direction* (0–100) 0 makes strokes hug the contours, 100
sweeps them all one way, set by *Common Angle* · *Wide Background Strokes*
(1–10) scales the brush up in uniform areas · *Expression* (5–100) uneven
edges and mixing paint · *Filling* (0–100) how completely the canvas is
covered · *Relief* (0–100) how far the strokes stand above the surface ·
*Lightening* (0–100) white scumbling · *Random Seed* · *Blend with Original*
with 16 blend modes.

**Strokes** — *Stroke Thickness* · *Max Stroke Length* (measured in brush
widths, so strokes stay strokes at any brush size) · *Min Stroke Length* (%
of the maximum) · *Hair Thickness* · *Brush Density* · *Intensity* (low
mixes the strokes, high keeps them crisp).

**Edge** — framing strokes around the picture: number, thickness, length,
edge smoothness, hair thickness, own colour or the colours underneath,
relief, and an elliptical arrangement. **Random** shuffles them.

**Abstract Art** — *Strokes* (Color, Saturation, Contrast) recolours random
strokes · *Correction* (Hue, Saturation, Brightness) shifts the whole image
· *Distortion* (Strength, Curvature, Random Seed) warps the shapes.

**Decoration** — *Light*: a studio key light with Vignette, Glow, Warmth,
its position (Light X / Light Y) and Spread — this is what gives a picture
the dark, glowing, old-master look, and it re-renders instantly without
repainting · *Canvas*: seven procedural surfaces (fine and rough canvas,
linen, corrugated paper, brick, ceramic, watercolour paper) or your own
sample, with relief, scale, light angle and strength · *Frame*: six styles ·
*Text*: inscription, signature or watermark, with font, position, colour,
size, opacity, angle, tiling and an optional logo. Drag the four tabs to
change the order the effects are applied in.

## Live sliders

Every slider updates the **After** image while you drag it, like
Photoshop. After the first **Run**, the After image is drawn by the graphics
card (WebGL 2), from the same layers the painting is made of:

| Sliders | What happens while you drag |
|---|---|
| Relief, Lightening, Blend with Original + Mode, all of Decoration (Light, Canvas, Frame, Text) | Exact and instant — the GPU redoes these on top of the painting, the same maths as Save |
| Intensity, Hair Thickness, Brush Density, Abstract Art colours and Correction, Edge smoothness / hair / relief | The strokes of the last Run are repainted on the GPU with the new look — instant |
| Stroke Thickness and Lengths, Simplicity, Direction, Common Angle, Wide Background, Expression, Filling, Random Seed, Distortion, Edge layout, guiding lines | The strokes are planned again: a quick, smaller plan while you drag, the full plan when you let go (a fraction of a second each), painted on the GPU |
| Canvas Oil sliders | Quick server drafts (about half a second each) |

A preview of new stroke settings is marked **Live preview — press Run to
paint it in full quality** and Run pulses: Run paints the same strokes on
the CPU, with the full bristle detail, and that is what Save writes. The
finishing and decoration sliders need no Run — Save always uses their
current values. The brushes work on the painting from the last Run, so
press Run first if the badge is showing.

The painting is made in two steps: `oilpaint/planner.py` decides every
stroke (vectorised with numpy, so a whole layer of strokes is traced at
once), then `engine.Brush` paints them on the CPU for Run, or
`static/js/live.js` paints them on the GPU for the preview. Without WebGL 2
the app still works: the finishing and decoration sliders are then
previewed by the server, and stroke sliders show the badge until Run.

### Run on the GPU

**Paint on: GPU — fast** (next to Quality, the default when the computer
supports WebGL 2) makes Run paint the strokes on the graphics card: the
server plans every stroke (about a second), the GPU paints them at full
size, and the server adds the relief, lightening and blending. It takes
seconds instead of tens of seconds, and the live sliders then restyle
exactly the strokes you see. **CPU — finest** paints with the CPU brush,
which has slightly crisper bristle and relief detail. Canvas Oil, Batch and
actions (.atn) always run on the CPU. If the GPU fails for
any reason, Run falls back to the CPU by itself.

## Tools

**Stroke Direction** — draw guiding lines on the Before tab and the brush
follows them; use the Eraser to remove one. **Smudge** mixes colours by
dragging pixels. **History Brush** fades the effect back to the photograph.
**Oil Brush** adds real strokes in a chosen colour, with paint reserve,
wet-paint mixing, brush cleaning and a flat-brush option. **3D Brush** adds
volume and relief without changing the colours. `Ctrl+Z` / `Ctrl+Y` undo and
redo, twenty levels deep.

## Canvas Oil style (no Photoshop needed)

Set **Style → Painting style** to **Canvas Oil**, or pick one of the
*Canvas Oil* presets, to get the look of the Envato "Canvas Oil Painting"
Photoshop action, made by OilStudio itself. The photo is cut into flat,
angular paint patches (smaller where there is detail) with knife dabs in
flat areas, then painted over with loose, real bristled brush strokes and a hand-drawn
sketch (outlines and hatching) showing through, and
finished with paint ridges, white canvas and weave showing through the
light areas, cross-hatched knife scratches and small glowing speckles.

| Slider | What it does |
|---|---|
| Brush Strokes | Real brush strokes over the patches (0 = flat knife patches only, fastest) |
| Stroke Size | Width of those strokes |
| Looseness | Loose, rough, quick brushwork that crosses edges and leaves gaps |
| Sketch Lines | Hand-drawn outlines and hatching showing through the paint (0 = none) |
| Patch Size | How big the knife-cut paint patches are |
| Detail | Smaller patches where the photo has detail |
| Drag | Patches run down the picture like wet paint |
| Knife Dabs | Small faceted dabs of different shade in flat areas |
| Relief | Paint ridges along the patch edges |
| Canvas | White canvas and weave showing through |
| Scratches | Cross-hatched knife scratches (0 = none) |
| Speckles | Small glowing paint spots |
| Contrast / Vibrance | Levels and colour boost |

Presets: *Canvas Oil*, *Canvas Oil - Clean (no scratches)*,
*Canvas Oil - Bold Knife*, *Canvas Oil - Fine Detail*, *Canvas Oil - Thick
Brush*, *Canvas Oil - Sketchy*, *Canvas Oil - Smooth*, *Canvas Oil - Flat
Knife (fast)*. With Brush Strokes on it takes
about as long as a normal painting at the same Quality; work at Draft while
choosing settings. Decoration, Abstract
Art, Blend with Original, the brushes and Batch all work with it. The code
is in `oilpaint/canvas_oil.py`.

## Presets and batch

Twenty-four built-in presets (Classic Oil, eight Canvas Oil variants, Portrait, Landscape, Impressionism,
Van Gogh Swirl, Palette Knife, Dry Brush, Abstract Art, Old Master Still
Life, Chiaroscuro Portrait, Museum Piece and more); save your own with
**Save**. **Batch** converts up to 24 images with
the current settings and returns them as a zip.

## Halftone style (no Photoshop, no template files)

**Painting style → Halftone** makes a vintage halftone print: sepia ink,
stipple grain, black specks along strong detail, a woven-cloth grid of dark
dots and light cracked scratches (`oilpaint/halftone.py`). It was rebuilt
from a Photoshop PSD template by measuring every step against the template's
own layers, and then made in code:

| Step | What it does | Sliders |
|---|---|---|
| Tone | Black & White (Photoshop's default mix), Levels, clarity + texture | Contrast, Clarity |
| Stipple | 9 grey steps; grain specks two steps darker (denser in the mid-tones); black specks on strong detail | Grain, Edges |
| Cloth | woven Aida cloth, Linear Burn: the dot grid | Dot Grid, Grid Size |
| Scratches | branching veins, Color Dodge: light broken lines | Scratches |
| Colour | brightness mapped onto a film-toned ramp from Ink to Paper | Ink, Paper, Film Tone |

Against the template's own result the average colour matches within one
level; grain density matches within a few percent at every brightness.
No texture, LUT or file from the template is used — the cloth, the
scratches and the colour ramp are generated — so the style can be sold.
Presets: *Halftone - Vintage Sepia*, *Clean Print*, *Heavy Grunge*,
*Blue Ink*, *Newspaper*.

## Painted Photo style (no Photoshop, no template files)

**Painting style → Painted Photo** turns the photo into flat, cut-out paint
patches on kraft paper with a warm film look (`oilpaint/painted.py`),
rebuilt from a Photoshop PSD template (Oil Paint, Poster Edges, Cutout,
Dry Brush, Texturizer and Palette Knife smart filters, two paper textures,
two film lookups) by measuring each step against the template's layers:

| Step | What it does | Sliders |
|---|---|---|
| Cut out | edge-preserving smoothing, then flat patches split by tone and colour family, each in its average colour | Tones, Detail |
| Brushwork | ragged patch edges, dark outlines on strong edges, palette-knife speckle, canvas relief | Outlines, Texture |
| Paper | generated kraft grain (Soft Light) and stained old paper (Multiply 50%) | Paper, Paper Grain |
| Film look | warm grade fitted to the template: orange skin, cool blue-grey shadows | Film Look |

Presets: *Painted Photo*, *Bold Poster*, *Fine Detail*, *Clean (no paper)*,
*Natural Colours*.

Halftone and Painted Photo are always made at the photo's full size (up to
4000 px, like the Photoshop templates) whatever **Quality** says, and shown
at up to 2400 px on screen; **Save** writes the full size.

## Impression style (no Photoshop, no action files)

**Painting style → Impression** (`oilpaint/impression.py`) rebuilds the
DesignRocket "Impression" action's look natively, measured against its PSD:
a median of several dab-shuffled copies of the photo along a stroke-flow field
(like the action's stack of Art History brush layers), Unsharp Mask twice and
a shadows lift; long light oil strokes laid on with Lighten through a ragged
stroke mask; embossed bristle grooves and a woven canvas laid on with
Overlay; and a white border. Sliders: Dabs, Swirl, Light Strokes, Relief,
Canvas, Border. No brush, pattern or action file is used.

## Actions (.atn) — played inside OilStudio, no Photoshop

The **Actions (.atn)** panel plays real Photoshop actions (Envato packs or
your own) inside OilStudio. Photoshop is not needed and not used. The result
comes back into the **After** tab, so Save, Snapshot, the brushes and Undo
all work on it.

**How it works** (`actions/`): the `.atn` file is a recording of Photoshop
steps, each with all its settings. OilStudio reads every step
(`actions/atn.py`) and plays it on its own Photoshop-like document
(`actions/player.py`): a tree of layers — pixel, adjustment, fill and group
layers — with opacity, fill, every Photoshop blend mode, layer masks with
feather, "blend if", pattern overlays, the selection, the work path, the
foreground/background colours and the current brush. Layers get the same
names Photoshop would give them ("Background copy 3", "Layer 7",
"Levels 1"…), so actions that select layers by name find them. At the end
the visible layers are composited.

| Step type | In OilStudio |
|---|---|
| Layers: select (also add / range), show, hide, new, Layer Via Copy, duplicate, merge, Merge Visible / stamp, delete, move, rename, groups, colour labels | exact |
| Masks: reveal all / hide all / from selection, invert, feather; selections from layer transparency; work path from selection | exact |
| Levels, Curves, Hue/Saturation, Vibrance, Desaturate, Invert, Posterize, Threshold, Exposure, Gradient Map, High Pass, Gaussian / Box / Motion blur, Median, Unsharp Mask, Add Noise, Emboss, Fill, gradient fill layers, pattern overlays, Transform (flip / scale / rotate) | exact or very close |
| Brightness/Contrast, Surface Blur | close |
| Stroke path with an `.abr` brush (size / angle / roundness jitter, scatter, count, flip) | close — same brush, same settings, its own random dabs |
| Filter Gallery: Glass, Sponge, Spatter, Palette Knife, Paint Daubs, Glowing Edges, Cutout, Charcoal, Sprayed Strokes, Crosshatch, Dry Brush, Watercolor, Accented Edges, Texturizer | close — OilStudio's own versions (Adobe never published these filters) |
| Anything else | skipped, like pressing **Continue** in Photoshop, and listed when the action ends |

When you choose an action the panel shows how many of its steps run
exactly, how many closely, and which (if any) are skipped.

**Files an action can come with** (all accepted, also inside an Envato
.zip): `.abr` brushes and `.pat` patterns are used by the steps that need
them (`actions/resources.py`); `.asl`, `.grd`, `.shc`, `.csh`, `.aco`,
`.ase`, `.tpl`, colour lookups and `.psd` templates are kept with the pack
(the `.atn` itself carries the styles and gradients it applies);
`.jsx`/`.jsxbin` scripts and `.zxp`/`.ccx` plugins only run inside
Photoshop, so OilStudio keeps them but does not use them.

**Using it**
1. Open an image as usual.
2. Pick an **Effect pack** and an **Action**.
3. Pick the **Focus area**. Most Envato actions only paint where a layer
   named `brush` is painted:
   * *Auto — find the subject* paints the brush layer over the main subject
     (`actions/focus.py`)
   * *Whole image* paints all of it
   * *No brush layer* is for actions that don't use one
4. **Long side** — Envato actions are made for photos about 3500 px long;
   every size in the action (brush diameters, blur radii, pattern scale) is
   scaled to the size you choose, so a smaller size looks the same, only
   less detailed, and runs faster.
5. **Run action.** Progress shows each step; **Stop** cancels.
6. **＋ Add action** adds a pack from inside the app: choose the `.atn`
   with every file it came with, or the whole Envato `.zip` (a zip inside
   the zip is unpacked too), give it a name, category and focus area, and
   press **Add to library**. A `.jpg`/`.png` you add becomes the preview.
   🗑 removes the selected pack from the library (your original files are
   not touched).
7. **Batch…** runs the action on up to 24 photos and downloads a zip. Any
   skipped steps are listed in `errors.txt`.

A big action (the Envato *Canvas Oil Painting* has 496 steps) takes about
half a minute to two minutes at 3500 px, depending on the computer. Packs
live in `ps_actions/` (a folder per pack); use **＋ Add action**
or copy a pack folder there. Decoded patterns are cached in `workdir/action-cache`.

**Licensing:** each Envato item is licensed to you. Using it in your own
work is fine. Don't give the action files, or an app that bundles them,
to people who don't hold their own licence.

## Quality and speed

`Quality` caps the longest side of the working image. Timings on a modest
2-core machine:

| Setting | Longest side | Typical |
|---|---|---|
| Draft | 650 px | 1–3 s |
| Normal | 1000 px | 3–7 s |
| High | 1500 px | 9–20 s |
| Max | 2400 px | 25–60 s |

(Stroke planning is vectorised since the live preview was added, which made
Run about 2× faster at Normal and 1.6× at Max than before.)

Work at Draft while you are finding the settings, then run once at High or
Max. Stroke size is proportional to the image, so the look stays the same as
you change quality — a higher setting gives more paint detail, not a
different painting.

## Layout

```
app.py                  Flask routes, session documents, batch, export
oilpaint/params.py      parameter schema, validation and clamping
oilpaint/engine.py      the painting engine: simplification, orientation
                        field, bristle brush (CPU), Run, finishing
                        (impasto relief, lightening, blend modes)
oilpaint/planner.py     stroke planning, vectorised: layers, filling,
                        edge strokes; the live preview's plans
oilpaint/abstract.py    Abstract Art: stroke recolouring, correction, warp
oilpaint/canvas_oil.py  the Canvas Oil style (Envato look without Photoshop)
oilpaint/halftone.py    the Halftone style (vintage halftone print)
oilpaint/painted.py     the Painted Photo style (cut-out paint on kraft paper)
oilpaint/impression.py  the Impression style (impressionist dabs on canvas)
oilpaint/decoration.py  studio light, canvas surfaces, frames, text
oilpaint/brushes.py     Smudge, History, Oil and 3D post-processing brushes
oilpaint/presets.py     built-in presets and the user's saved ones
actions/                Photoshop actions (.atn) played without Photoshop:
                        atn.py (reader), player.py (layers and steps),
                        filters.py, resources.py (.abr/.pat), focus.py,
                        library.py (the packs)
templates/, static/     the workspace UI; static/js/live.js is the WebGL 2
                        live preview (GPU strokes, finishing, decoration)
samples/                a few photographs to try
```
